name: github-pr
description: GitHubのPRのタイトルと説明文を自動生成し、PRを作成するコマンド
---

## Description

このコマンドは以下の作業を自動で実行します：

1. 現在の作業ブランチと引数で渡されたブランチ(渡されてない場合はmain)との**差分**を分析
2. 差分内容に基づき、**Pull Request のタイトル** と **説明文** を自動生成
3. 生成したタイトルと説明文を使って、PRを新規作成

実行ログは日本語で出力します。

---

## Implementation

- 現在のブランチと引数で渡されたブランチ(渡されてない場合はmain)との差分を確認する(現在のブランチと比較するブランチが同じ場合はエラー終了)
- PRの詳細は現在のブランチが新たな開発項目として差分内容を確認し以下の項目を書くこと
    - 概要
    - 変更内容
- 現在のブランチが既にリモートに存在するかチェック(無い場合のみリモートにプッシュする)
- PRは引数で指定されたブランチをベースブランチとして作成する

---

## 使用例
/github-pr
/github-pr feature/hoge
